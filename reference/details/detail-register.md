# Detail register — the junctions worth drawing

Generated by `docgen/detail_schedule.py`. A detail earns its place where two build-ups
meet and the insulation, the damp proof course or the fire separation has to be
resolved. A mid-wall section restates the specification in a picture and is never
queried, so it is not on this list.

Layer data for every build-up named here is in `build-up-schedule.md`, and the same
data in machine-readable form is in `build-up-schedule.json`.
